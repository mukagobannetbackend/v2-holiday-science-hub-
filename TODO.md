# Holiday Coaching Hub — Delivery Checklist

- [ ] Foundation: Flask structure, responsive layout, dark/light theme, login/logout, roles, password change.
- [ ] Verification: student register, class assignment, payment status, admin approval, temporary-password flow, suspension.
- [ ] Library: O-Level/A-Level sections, S1–S6 filtering, staff upload, class-scoped viewer, download request/approval.
- [ ] Timetable: class-scoped lessons, Google Meet URL, filters, upcoming/live state, announcements and in-app notices.
- [ ] Assessments: written questions, typed answers, draft/submission, optional script upload, marking guide, marks and feedback release.
- [ ] Video and records: YouTube links, class/subject/topic filters, dashboard summaries, audit log, CSV exports.
- [ ] Security: hashed passwords, RBAC, server-side class checks, safe uploads, CSRF-style state token, audit trail, no public file paths.
- [ ] Validation: automated tests and manual smoke checks completed before packaging.
